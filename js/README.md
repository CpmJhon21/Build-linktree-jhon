# PixelLink Builder - Linktree Builder dengan Tema Pixel Art

PixelLink Builder adalah aplikasi web untuk membuat halaman Linktree tanpa coding. Dibangun dengan HTML, CSS, dan JavaScript murni (tanpa backend atau database).

## Fitur Utama

- **3 Template Unik**: Pixel Art Modern, Cyber Neon, dan Dark Futuristic
- **Preview Realtime**: Lihat perubahan secara langsung
- **Responsif**: Mendukung desktop, tablet, dan mobile
- **Export Mudah**: Copy HTML atau download file HTML siap hosting
- **Background Music**: Dengan kontrol volume dan autoplay yang aman
- **Upload Gambar**: Upload foto profil atau gunakan URL
- **Media Sosial Dinamis**: Tambah/hapus platform media sosial
- **Link Kustom**: Buat link button dengan teks kustom

## Cara Menggunakan

1. Buka `index.html` di browser
2. Isi form profil (nama, bio, foto)
3. Pilih template yang diinginkan
4. Tambahkan link media sosial dan custom link
5. Atur background music (opsional)
6. Preview di mode desktop atau mobile
7. Export dengan copy HTML atau download file

## Deployment

Website ini siap di-hosting di:
- **Netlify**: Drag & drop folder ke Netlify
- **Vercel**: Import dari GitHub/GitLab
- **Replit**: Upload file atau clone dari GitHub
- **GitHub Pages**: Upload ke repository GitHub
